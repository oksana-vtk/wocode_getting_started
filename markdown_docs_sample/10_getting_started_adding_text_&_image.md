# Adding Text & Image

You have a few options for adding text to your website, including the Text widget and the Title widget, as well as the Text & Image widget. This widget allows you to add both content and an associated image at once to save time and keep these areas of your website consistent.

To add this widget, open the Widgets tab and search for the Text & Image widget.

![image](https://app.wocode.com/wp-content/uploads/2018/06/textimage-1.jpg)

Drag this widget into the desired location of your editor and it will open the content and design options. Using the content tab you can select the image and add/edit the content.

![image](https://app.wocode.com/wp-content/uploads/2018/06/textimage-2.jpg)

Using the design tab you can change aspects of the image and text: size, position, color, and style, as well as spacing.

![image](https://app.wocode.com/wp-content/uploads/2018/06/textimage-3.jpg)
