# Spacing

The spacing for all site editor elements – rows, columns, and widgets – can be customized using the design menu. By changing the inner spacing (padding) and the outer spacing (margin) you can alter the appearance of your element.

To change the spacing. Right click on any row, column, or widget and select “Edit Design.”

![image](https://app.wocode.com/wp-content/uploads/2018/07/spacing-1.jpg)

Select the “Spacing” tab.

![image](https://app.wocode.com/wp-content/uploads/2018/07/spacing-2.jpg)

To alter the outer spacing/margin, click on the outer box and edit the numbers or use the slider.

![image](https://app.wocode.com/wp-content/uploads/2018/07/spacing-3.jpg)

To alter the inner spacing/padding, click on the inner box and edit the numbers or use the slider.

![image](https://app.wocode.com/wp-content/uploads/2018/07/spacing-4.jpg)

Note: if you see spacing that you are unable to change, ensure you check the widget, column, AND row.
