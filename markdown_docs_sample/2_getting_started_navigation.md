# Navigation

Navigation and subnavigation menus differ between templates and are created automatically based on your pages.

You can make edits to your menus by right-clicking on the navigation and selecting “Edit Design.”

![image](https://app.wocode.com/wp-content/uploads/2018/07/navigation-1.jpg)

From the design section you can change the navigation layout and orientation. If your site includes subpages, you can change the layout here.

Note: switching the layout will reset any customization.

![image](https://app.wocode.com/wp-content/uploads/2018/07/navigation-2.jpg)

Select the Pages tab to customize the navigation bar (color, spacing, text), font, the direction of navigation, as well as the visibility, spacing and divider between items.

![image](https://app.wocode.com/wp-content/uploads/2018/07/navigation-3.jpg)

Scroll down to customize the hover effect for the navigation.

![image](https://app.wocode.com/wp-content/uploads/2018/07/navigation-4.jpg)

Select the “Subpages” tab to customize the subnavigation.

![image](https://app.wocode.com/wp-content/uploads/2018/07/navigation-5.jpg)

Finally, select the “Spacing” tab to adjust the spacing of your navigation.

![image](https://app.wocode.com/wp-content/uploads/2018/07/navigation-6.jpg)
