# Editing Text

You can edit elements of text by selecting any text block (Text widget).

![image](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5ada36872c7d3a0e93678b41/images/65de487f6ba1d916ec466df2/file-pmhB4puUVn.png)

Then select the text you want to edit and use the editor to change style, font, size, alignment, and even add links.

![image](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5ada36872c7d3a0e93678b41/images/65de48a90f2a4c04f24d9a77/file-ovZekJ4RO5.png)
