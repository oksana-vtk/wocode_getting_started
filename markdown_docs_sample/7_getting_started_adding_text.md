# Adding Text

You can easily add a paragraph to your site by using the Text widget.

Note: this widget is ideal for adding a paragraph or block of information. If you want to add a large title or sub-title, select the Title widget. Alternatively, you can use the Text & Image widget if your paragraph includes an image.

To add a simple block of text, open the Widgets tab and search for the Text widget.

![image](https://app.wocode.com/wp-content/uploads/2018/06/paragraph-1.jpg)

Drag this widget into the desired location of your editor and this will create a simple paragraph. You can click on the block to enter your text, as well as open the inline editor to make basic font style and size changes, alignment edits, etc.

![image](https://app.wocode.com/wp-content/uploads/2018/06/paragraph-2.jpg)

Right clicking on the Text widget will open more options.

![image](https://app.wocode.com/wp-content/uploads/2018/06/paragraph-3.jpg)

Click “Edit Design” to adjust style and spacing.

![image](https://app.wocode.com/wp-content/uploads/2018/06/paragraph-4.jpg)
